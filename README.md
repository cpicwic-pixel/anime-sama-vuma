# Anime-Sama — addon mHub v2 pour Vuma

## Contenu
- Manifeste mHub v2.
- Catalogue statique de 8 séries d'anime.
- Une fiche JSON par série.
- Liens externes vers le site principal Anime-Sama ; aucun flux vidéo fourni.

## Déploiement
1. Dans GitHub, ouvre Settings → Pages.
2. Active GitHub Pages depuis la branche `main`, dossier `/ (root)`.
3. Une fois publié, teste le manifeste à l'adresse :
   `https://cpicwic-pixel.github.io/anime-sama-vuma/mhub-addon.json`
4. Soumets l'addon via https://www.mhub.mx/fr/community → « Proposer un addon », si le répertoire communautaire est disponible pour ta version.

## Limites
Ceci est un addon de découverte statique, pas une API connectée en direct à Anime-Sama. Les métadonnées ne sont pas mises à jour automatiquement. Aucun flux vidéo, lien d'épisode ou sous-titre protégé n'est récupéré ou redistribué. Une version dynamique exige une source de données dont l'accès et les conditions d'utilisation autorisent l'intégration.
